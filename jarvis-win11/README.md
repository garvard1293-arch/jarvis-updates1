# JARVIS — голосовой помощник и Студия кода для Windows 11

Русскоязычный помощник с тёмным GUI, локальным распознаванием слова «Джарвис» через Vosk и голосовыми ответами через Windows SAPI. Чат и Студия кода работают с локальной моделью Ollama; при желании можно выбрать Gemini API.

## Возможности первой версии

- Современное окно чата с индикатором состояния, голосовой активацией и настройками режима.
- Локальное распознавание русского слова-пробуждения «Джарвис»; микрофон не передаётся в облако.
- Локальная модель Ollama или Gemini API, выбираемые в настройках.
- Озвучивание ответов средствами Windows, если в системе установлен русский голос.
- Ограниченный набор локальных действий: открыть Блокнот, Калькулятор, Проводник, Диспетчер задач, браузер, YouTube и параметры Windows.
- Кнопка **«Разрешить свободу действий»** включает дополнительные команды открытия папок пользователя, Paint и Ножниц. Включение требует подтверждения; режим можно сразу выключить той же кнопкой.
- Студия кода и игр: генерация структуры и файлов проекта для Godot 4, Unity, Unreal Engine 5, GameMaker, Pygame и Roblox Studio.
- Предпросмотр сгенерированных файлов; запись выполняется только после подтверждения, а перезапись — после отдельного подтверждения. JARVIS сам не запускает сгенерированный код.
- Фразы «открой студию кода», «создай игру» и «напиши программу» открывают Студию; описание задачи можно сказать или ввести по-русски.
- Ключ Gemini хранится через Windows Credential Manager (keyring), а не в `settings.json`.

Это локальный помощник и генератор файлов, а не полностью автономный системный агент. Режим свободы действий расширяет только фиксированный allowlist; он не разрешает произвольные команды, PowerShell-скрипты, удаление/изменение произвольных файлов или запуск сгенерированного кода.

## Установка

1. Установите 64-битный Python 3.11 с [python.org](https://www.python.org/downloads/). В установщике включите **Add Python to PATH**.
2. Распакуйте папку проекта в обычное место, например `C:\Users\ВашеИмя\Apps\JARVIS`.
3. Запустите `install.bat` и дождитесь установки библиотек и загрузки компактной русской модели Vosk.
4. Для локального диалога установите [Ollama для Windows](https://ollama.com/download/windows), затем откройте Терминал и выполните `ollama pull qwen3:8b`.
5. Запустите `start.bat`. При первом запуске приложение автоматически попробует включить локальное распознавание микрофона.

Модель Qwen3 8B в Ollama занимает несколько гигабайт на диске. Если она работает медленно или заканчивается видеопамять, установите более лёгкую модель через Ollama и укажите её точное имя в настройках.

## Gemini API

Создайте ключ в [Google AI Studio](https://aistudio.google.com/), откройте **Настройки** в JARVIS, выберите **Облако · Gemini API** и вставьте ключ в поле. Ключ сохраняется в хранилище учётных данных Windows. Не публикуйте его и не отправляйте в чат.

Бесплатные модели, квоты и правила обработки данных зависят от проекта и могут меняться. При использовании облачного режима только текст текущего сообщения и ограниченный контекст разговора отправляются сервису. Не передавайте конфиденциальную информацию.

## Создание программ и игр

В Студии выберите движок, задачу, рабочую папку и при необходимости путь к редактору движка. Файлы сначала появятся в предпросмотре. Проверьте пути и содержимое, затем нажмите **Проверить и сохранить…**. Сгенерированный проект не запускается автоматически. Для голосового запуска скажите «Джарвис, создай игру» или «открой студию кода».

Движки устанавливаются отдельно, потому что редакторы и SDK занимают много места и имеют собственные условия лицензии. Для первого проекта рекомендую Godot: его версия для Windows распаковывается и запускается без отдельного установщика. Официальные страницы: [Godot для Windows](https://godotengine.org/download/windows/), [Unity Hub](https://unity.com/download), [Unreal Engine через Epic Games Launcher](https://www.unrealengine.com/en-US/download). Студия также поддерживает GameMaker, Pygame и Roblox Studio. После установки укажи исполняемый файл редактора: например, `Unity.exe` внутри установки Unity Editor или `UnrealEditor.exe`, а не установщик.

На компьютере с 16 ГБ ОЗУ разумно начать с Godot или небольшого Pygame-проекта. Unity и особенно крупные проекты Unreal могут быть требовательнее; движки не включены в архив JARVIS и не устанавливаются автоматически.

### Расширенный кодовый агент OpenJarvis (необязательно)

Обычная генерация через Ollama/Gemini работает без OpenJarvis. Для многошагового локального агента сначала установи Ollama и загрузи `qwen3:8b`, затем запусти `setup_openjarvis_backend.bat` и после установки — `start_openjarvis_backend.bat`. В Студии выбери **OpenJarvis agent · локально, ограниченный доступ**. Setup загружает зафиксированный [OpenJarvis commit](https://github.com/open-jarvis/OpenJarvis/tree/40092da25efb2288f2650d0380d5224d3c46b9a1) под Apache 2.0.

Конфигурация включает только `file_read`, `file_write` и `think`, причём файловый доступ ограничен временной папкой `AgentStaging`; `shell_exec`, исполнение Python, внешние MCP-инструменты и сетевые поисковые инструменты отключены. Файлы после генерации попадают в предпросмотр JARVIS и копируются в рабочую папку только после явного подтверждения. Если OpenJarvis не нужен, оставь прямой режим Ollama/Gemini.

## Автозапуск

Если хотите, чтобы приложение запускалось вместе с Windows и сразу ожидало слово «Джарвис», сначала проверьте, что `start.bat` работает, затем запустите `enable_autostart.bat`. Чтобы отменить, запустите `disable_autostart.bat`. Автозапуск создаёт обычный ярлык в папке автозагрузки текущего пользователя.

## Приватность и ограничения

Пока JARVIS запущен и микрофон включён, Vosk постоянно анализирует звук локально, чтобы обнаружить wake-word. После фразы «Джарвис» приложение распознаёт следующую короткую команду. В локальном режиме текст остаётся на компьютере; в Gemini-режиме он отправляется в облако только после активации.

Сохранение в Студии ограничено выбранной рабочей папкой; перед изменением существующих файлов требуется подтверждение. Не запускайте неизвестный код, пока не просмотрели его. Помощник подходит для обычных программ, собственных игр, официальных модов и одиночных/офлайн-модов. Он не предназначен для читов в сетевых играх, обхода античита, внедрения в игровые процессы или сокрытия таких вмешательств.

Кнопка свободы действий добавляет только открытие заранее перечисленных пользовательских папок и двух стандартных приложений Windows. Она не снимает ограничения на выполнение команд и не превращает чат-модель в администратора Windows.

Если слово пробуждения распознаётся нестабильно, попробуйте говорить чётко, проверьте выбранный микрофон в параметрах Windows и уровень его громкости. Маленькая офлайн-модель Vosk может ошибаться при шуме или на расстоянии.

## Структура

- `jarvis_app.py` — GUI, локальная голосовая активация, обработчики чата и безопасных команд.
- `studio.py` — генерация, предпросмотр и подтверждаемое сохранение файлов для игровых движков.
- `requirements.txt` — Python-зависимости.
- `install.bat` — установка окружения и модели распознавания.
- `start.bat` — запуск.
- `setup_openjarvis_backend.bat` / `.ps1` — необязательная установка локального code-agent backend с ограниченным доступом.
- `start_openjarvis_backend.bat` — ручной запуск локального API-агента; приложение работает и без него.
- `enable_autostart.bat` / `disable_autostart.bat` — включение и отключение запуска вместе с Windows.
- `DEV_HANDOFF_RU.md` — журнал решений, реализованных функций, проверок и плана следующего этапа для продолжения в новом разговоре.
- `previews/` — снимки текущих экранов приложения (Qt render в тестовой среде, не скриншоты из Windows пользователя).

## Сохранение ключа и обновления

Gemini API-ключ сохраняется кнопкой «Сохранить» в защищённом хранилище учётных данных Windows через библиотеку `keyring`. Ключ не записывается в `settings.json`, архив обновления или GitHub. Чтобы удалить его, откройте настройки и включите пункт «Удалить сохранённый Gemini-ключ».

В меню слева есть кнопка «Проверить обновления». Приложение читает `update.json` из репозитория `garvard1293-arch/jarvis-updates1`. Перед установкой проверяются ссылка и SHA-256 архива, затем создаётся резервная копия папки проекта с суффиксом `.backup`. Настройки и ключ лежат отдельно в `%APPDATA%\\JarvisAssistant` и не перезаписываются.

Формат `update.json`:

```json
{
  "version": "1.2.0",
  "notes": "Описание изменений",
  "download_url": "https://github.com/garvard1293-arch/jarvis-updates1/releases/download/v1.2.0/JARVIS.zip",
  "sha256": "SHA256_АРХИВА"
}
```
